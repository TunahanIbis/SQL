# Miramax Movie Production Database

This project is a simple SQLite-based database management system for handling movie production data. The console application allows users to manage and interact with tables such as `MOVIE`, `PRODUCER`, `ACTOR`, `DIRECTOR`, `THEATER`, and their relationships through associative tables.

## Features

- **Add a Record**: Insert a new record into any table.
- **Delete a Record**: Delete a record from any table based on the primary key.
- **Update a Record**: Update an existing record in a selected table.
- **Display Records**: View all records from a selected table.
- **Execute JOIN Operations**: Perform a JOIN to display movies along with associated producers, actors, directors, and theaters.

## Requirements

- Python 3.x
- sqlite3 (comes pre-installed with Python)

## Setup

1. Clone or download the repository.
2. Run the cells of ipynb file.
3. The first cell will create a blank database and insert data inside of it.
4. Console application works on the second cell.
5. You can directly run the second cell whenever after you run the first one.
